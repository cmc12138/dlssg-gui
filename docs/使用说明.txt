DLSSG GUI —— 给 RTX 20/30 系显卡开 DLSS 帧生成的图形化工具
=========================================================

里面有两个文件，随便挑一个用：

1) DLSSG-GUI-0.1.0-portable.exe   便携版：双击就能用，不用安装
   数据（运行库、备份、配置）会放在同一个文件夹的 data\ 里，
   整个文件夹复制到别的机器上，配置和备份一起带走。

2) DLSSG-GUI-0.1.0-x64.exe        安装包：装到本机，带开始菜单和桌面快捷方式

第一次使用（三步）
------------------
1. 打开「运行库」，先看「上游状态」——它会自动读出上游最新版本和所有发布包，
   点主分支那个的「下载」（主分支 = 310.9 运行库，最高 6X；仓库里的 310.1 目录最高 4X）。
   下不下来就把上游仓库的 ZIP 下载下来用「导入 ZIP」。
2. 打开「游戏」→「扫描本机游戏」，把要改的游戏加进列表
   （也可以「手动添加游戏目录」，指到游戏根目录即可，程序会自己找渲染 EXE 目录）。
3. 点游戏的「配置 / 注入」→ 确认渲染 EXE 目录 → 「开始注入」。

注入完启动游戏，在图形设置里打开 DLSS 帧生成，选 2X / 3X / 4X。
想要 6X：游戏自己得支持（菜单里有 6X 或「动态」），并且把「倍率上限」改成 5。
出厂默认上限是 4X（上游从 0.3.1 起把默认从 6X 调回 4X，因为默认 6X 观感不好）。

看到「上游有更新」就点「更新」：新版本会下载到新的运行库目录，旧版保留着，
已注入的游戏要重新注入一次才会用上新版本。

注意事项
--------
* 注入前一定要完全退出游戏，程序会检查进程，游戏还在跑就不让写。
* 只能用在单机 3A 上。千万别在带反作弊的网游里用（PUBG、Valorant、
  带 EAC / BattlEye 的游戏等等），DLL 注入会被当成外挂，100% 封号。
* 基础帧率太低的时候插帧观感会变差，适当降点画质把基础帧率抬上去再开。
* 不想要了：游戏详情 → 「文件与备份」→「一键还原」，会把游戏目录恢复成注入前的样子。
* 游戏画质设置里如果帧生成选项还是灰的，说明这游戏本身不支持 DLSS 帧生成，
  或者代理 DLL 没被加载——去「日志」页看有没有 runtime_redirect，或者换个代理名
  （version.dll 不行就试 winmm.dll）。

卡普空游戏（RE Engine）要特别注意
---------------------------------
Pragmata、生化危机安魂曲、龙之信条 2、怪物猎人荒野这类新卡普空游戏，会拒绝加载游戏
目录里它不认识的 DLL——只放 version.dll 会“直接崩在启动”，换成 dxgi.dll / winmm.dll
也一样。解决办法是先装 REFramework（这些游戏放行的加载入口）：

1. 在游戏详情页点「下载并安装 REFramework」（约 13MB，自动装进游戏根目录）
   官方下载通道在部分网络下连不上，程序会自动换镜像；都不行就用「用本地 ZIP 安装」，
   自己去 github.com/praydog/REFramework-nightly 的 releases 下 REFramework.zip。
2. 装完先启动一次游戏，让它加载框架（游戏目录里会生成 reframework 文件夹），然后退出。
3. 回到工具里重新注入代理 DLL，之后游戏里就能开 DLSS 帧生成。

不想留了：同一张卡片上有「卸载 REFramework」，会把覆盖过的 dinput8.dll 还原回去。

几个实测经验（都是上游 issue 里的结论）
--------------------------------------
* 《光与影：33 号远征队》和《黑神话：悟空》的 DLSS 埋在 Plugins 深处（8 层），
  现在扫描能正确认出，注入目录分别是 Sandfall\Binaries\Win64 和 b1\Binaries\Win64。
* 远征队自带的 Streamline 插件是 2.7.30，只有 4X；倍率上限就用默认的 4X，
  千万别开「ForcePluginFrames」去强推 6X（上游实测会让整个帧生成硬失败）。
* 一个游戏在列表里只会有一条记录；如果你以前加重复了，游戏页会提示「合并重复条目」。
* 同一个游戏目录里别留多个代理 DLL（虽然现在不致命了），只留一个最省事。

机器要求
--------
Windows 10/11 x64、D3D12 游戏、NVIDIA 驱动带 NGX/NVAPI（建议 580 以上，
591.86 / 610.74 实测可用）。显卡是 RTX 20/30 系（SM86 / SM75）。

说明：本工具不含 NVIDIA 的运行库，需要按上面第一步自己下载；上游开源项目是
github.com/sdli1995/dlssg_for_sm86。
